- New: `paddock app run NAME --backend macvm` on macOS starts one app session in paddock's own macOS guest VM through the new `paddock-vm app` helper: the profile folder with the clone of the golden, the data disk and the saved state, the start decision (fresh, repair, cold, warm, or stale with its reason), the profile lock, the two VM slots of the Mac, the quit path with pause, save and stop, the session records, `paddock app stop NAME` and the macOS guest lines of `paddock app list`. The session talks to the guest agent `paddock-guest` with the protocol of `src/macvm/proto.rs`: the hello gets the token and the agent update, the data disk is prepared on the first boot, and every request has a timeout.
