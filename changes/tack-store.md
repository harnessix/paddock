- New: `paddock tack`, the first part of tack. The `[tack]` table of the user configuration names secrets, their store (the system keyring or a password manager command) and the programs that may receive them. `paddock tack import NAME` moves a value from your shell startup files, environment.d and named .env files into the store, and leaves the reference `tack://NAME`. It is a dry run without `--yes`, and it backs up each changed file. `paddock tack list`, `paddock explain` and `paddock doctor` show the state. No program receives a value yet: that comes in a later version.
- Changed: a project `paddock.toml` with a table that only the user configuration may have, such as `[credentials]` or `[tack]`, now fails with a message that names the table.
