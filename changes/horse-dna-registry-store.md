- New: (experimental) published DNA in the horse store. A resolved artifact is stored by its hash, and each fetch writes one `dna.fetch` event. A use grafts the artifact into a horse with the usual compatibility check, and its traits name the registry reference as their origin in `explain`. A publish writes the current DNA of a horse with its parent DNAs as a signed manifest into an index, and writes one `dna.publish` event. A fetched DNA grants no capability. There is no command for it yet.
