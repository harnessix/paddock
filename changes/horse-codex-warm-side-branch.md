- New: `paddock horse fork SESSION --warm` opens a warm side branch of a Codex session that a run in horse mode holds. It is an ephemeral fork of the live thread at its head, under the cache key of the parent, and the run holds it like the parent. The parent waits until `paddock horse fork SIDE --close` or the end of the run. The prefix guard saves a warm verdict for it, and a persisted fork stays cold.
- New: paddock marks the nodes that it builds from a live channel as `live`, and `paddock horse log` shows the mark. A projection of a session that has a live node fails with "not a native original; persist it with the harness first".
