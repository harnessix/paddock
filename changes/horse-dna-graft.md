- New: (experimental) horse DNA graft, adapt, explain and revert. `paddock horse graft HOST DONOR` combines two horses: HOST keeps its id and sessions and gains the traits of DONOR. Where a trait value differs, the value of HOST stays and the value of DONOR becomes an alternative. A different policy value, or a capability of DONOR that HOST lacks, refuses the graft and writes nothing. `paddock horse move SESSION HORSE` moves an idle session to another horse, grafts the DNA of its old horse into the new one, and adds a lineage step. `paddock horse guard SESSION --move HORSE` shows that a move keeps the cached prefix. At the end of each run in horse mode, three rules set the traits `runs`, `harnesses` and `reliability`. `paddock horse explain HORSE` shows where each trait comes from, the DNA events and the lineage of each session. `paddock explain` shows this for a run in horse mode. `paddock horse dna revert HORSE HASH` goes back to an earlier DNA of the horse, and `dna set HORSE HASH` now does the same.
