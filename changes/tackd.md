- New: tackd, the service of tack. `sudo paddock tack setup` installs it as a root systemd unit on Linux or a LaunchDaemon on macOS, runs a root-owned copy of paddock, and updates it in place when you run it again. It decides which allowlisted program may receive which secret, from the program's real path and hash (or macOS signer), its argument shapes and its parent processes. A paddock sandbox or a coding agent among them is refused unless a `callers` rule says otherwise. It starts no program yet.
- New: `paddock tack status`, `paddock tack check`, `paddock tack audit` and `sudo paddock tack remove`. The audit log has one line per decision, never a value or an argument. `paddock doctor` shows whether tackd runs and its version, or the rootless mode.
- New: an allow entry of `[tack]` can have `args`, the allowed argument shapes. A `callers` rule for a kind can say `action = "allow"`.
