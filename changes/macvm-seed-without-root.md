- Fix: `paddock macvm setup` no longer needs root for the seed step. On a Mac, the seed failed as a normal user because a guest disk that never booted has no `Users` folder and the host cannot set the owners that launchd wants. The setup now writes a seed folder in the golden folder and shares it read-only with the guest in the guided step. The window shows one command for Terminal of the guest, `sudo /bin/sh "/Volumes/My Shared Files/paddock-seed/install.sh"`, which installs the agent with the right owners and starts it. A golden that an older build left in the seed step continues with the new step.
- New: the golden build writes `events.jsonl` in the golden folder: each state start and end, and each wait on the person (`account created`, `seed installed`, `trusted`).
