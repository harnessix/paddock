- New: on the macOS guest route, VoiceOver and other Accessibility clients read the controls of the guest window through the host window. The first query of a session window's children starts a mirror of the guest window's Accessibility tree (roles, titles, values, frames, four levels deep), the guest agent keeps it current while the window is key, a press on a mirrored button presses it in the guest, and a value set on a mirrored field sets it in the guest. A tree above 64 KiB or 1500 elements loses whole subtrees, never half a list.
- New: a press on a mirror element from an earlier tree, a disabled one, or one while the guest agent is away is dropped with a line in the event log, not sent; when the `ax.tree` request has no answer in 2 s the host keeps the last tree.
- `paddock app status --json` has `ax` (`window`, `elements`, `watched`, `away`), events.jsonl has the `ax` lines, the control socket answers `window ax`, and `packaging/macos/checks/macvm-input.sh voiceover` checks the mirror and a press through it on a Mac.
