- Fix: `paddock macvm setup` makes the `~/Downloads` link of the guest in the stopped guest, with the owner of the guest account. The configure step `downloads-link` only reads the link now. Before, the step waited on a Files and Folders prompt in the guest and was killed after 30 s.
- Fix: the end of a session shuts the guest down with `sudo shutdown -h now` and the guest password, with a limit of 15 s. Before, it asked System Events, and macOS asked for an Automation permission that nobody grants. If the agent refuses the shutdown, the VM stops at once with the reason in the event log.
- Removed: the configure steps `black-desktop` and `no-time-machine`. On macOS 26 and later the desktop picture lives in a private store of the wallpaper agent that no public API writes, and the guest desktop never shows. `tmutil disable` needs Full Disk Access, and Time Machine does nothing in a golden, which has no backup disk.
