- New: the firewall of paddock's macOS guest (network mode `ask`, the default of app profiles there): the first connection of an app to a host that no rule covers asks you, with a panel next to the app's window, in `paddock approvals`, and with `paddock approvals answer ID --allow-once | --allow-session | --allow-always | --deny | --deny-always`. The rules live in `~/.config/paddock/firewall/NAME.toml` (mode 0600), `paddock app rules NAME [list | add | remove]` edits them, the profile seeds the hosts of a plain login (`seed_hosts`), and `paddock app log NAME` shows every decision with the host, the rule and the bytes.
- Security: in modes `api` and `allowlist` the host list decides before any firewall rule, so a forged guest identity cannot pass it; a rule that allows every host needs `--yes-all-hosts`.
- New: the approver hook can answer `connect` questions of the firewall when its configuration names that capability.
