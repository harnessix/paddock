- New: `paddock-guest`, the agent of paddock's macOS guest VM for app mode on macOS. It dials the host over vsock, reports the windows of the app with their geometry, moves, raises, minimizes and closes them on request, launches and quits the app, reports health, runs the configure steps of the golden build, keeps the input source equal to the host's, updates itself from the `agent` share when the host is another version, and keeps the app across its own restart. The protocol (`src/macvm/proto.rs`) has a major and minor version, a `req` id and a timeout per request, an error code enum, and log texts without the token, the password or clipboard text. The pure parts (the protocol, the window diff, the dispatch, the update, the log rotation, the configure argv, the relaunch counter) have Linux tests. The vsock ports 1030 to 1032 are reserved. `packaging/macos/build-guest.sh` builds and signs the agent; `packaging/macos/checks/macvm-agent.sh` checks it on a Mac.
