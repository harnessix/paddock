- New: `run = "host"` runs a device program on the host as you: an `exec` command per request in `cwd` (default: your home) with your whole environment and the fixed values of `env`, or a `serve` program once per run on a socket of the run. The supervisor is `paddock device-serve --host`, started at the first request and ended with the run, so the envelope, the exit mapping, `timeout`, the kill of the process group, `concurrency` and the log are the ones of every device program. A missing `cwd` answers `status: error` with `message: cwd ~/notes does not exist`. A command that is not on your PATH answers `message: NAME is not on the PATH of the host`.
- Security: a host device is marked everywhere. The card says "allow the device `notes` for this sandbox: it runs ON THE HOST as you" with the command and `cwd`, and never skips, whatever `mode` says. The catalog has `"run": "host"` and a `request` text that begins with "Runs on the host as you, with your home, your keys and your network." `paddock device ls` prints `HOST`, `paddock doctor` lists the host devices under "devices that run on the host as you" with their commands, `paddock ps` shows `device notes (host, running 3m, pid N)` under the sandbox (`--json`: `devices`), and every audit line has `"run": "host"`.
- New: `paddock device check NAME` for a host device prints the warning line first, then starts the supervisor on the host, waits for its health, prints the start time and stops it. `paddock device stop|restart NAME --sandbox ID` reach a host instance as they reach a device sandbox.
- New: a host instance writes the same state file as a device sandbox, `~/.local/state/paddock/devices/instances/NAME/SANDBOX.json`, with `run: host`, so `paddock ps`, `paddock device ls` and the stale cleanup treat both alike.
- Changed: `env_pass` is refused for `run = "host"` (the program gets your whole environment) and, at the top level of a sandbox table, names `[devices.NAME.sandbox]` as its place. A host device takes `env = { NAME = "value" }` instead.
- Changed: a `serve` table with `run = "host"` is served. Before, it answered "not available yet".
