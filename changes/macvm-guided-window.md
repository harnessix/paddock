- Changed: the guided window of `paddock macvm setup` can be resized. Its first frame fits inside the visible part of the main screen, so it is never under the Dock or the menu bar. The guest view keeps the aspect ratio of the guest display, and the side panel scrolls, so no text is cut off.
- New: the panel shows the guest password in a large field with Copy, Type the password into the guest and Type the command into the guest. The guest has no clipboard before its agent runs, so the buttons send the text to the guest as key presses of a US keyboard. Click into the field in the guest first, then the button.
- Changed: the made guest password has 20 lowercase letters without `a`, `m`, `q`, `w`, `y` and `z` (86 bits), not 16 letters and digits. These letters are on the same key on US, UK, German, French and Chinese keyboards. A password of an older paddock in the keyring still works.
- New: if the guest refuses the password in the configure step, the setup does not start over. The panel asks for the password that you set in Setup Assistant, paddock keeps it in its keyring and runs the configure step again, at most 5 times.
