- New: (experimental) a Claude Code codec for the horse store. It reads Claude Code 2.1.317 transcripts row by row, keeps each row by its uuid, and keeps the rows that Claude Code drops when it rewrites a large transcript. It writes a session or a paddock fork back as a transcript in the project folder of the cwd, in the shape of a native `/branch` fork. It refuses other Claude Code versions. The hidden commands are `paddock horse ingest-claude` and `paddock horse project-claude`.
