- New: on the macOS guest route, the guest holds the host's keyboard layout and input source while a session window is key; an input method that composes (Pinyin, Wubi, Zhuyin, Cangjie, Kotoeri, Hangul, Telex and the third party ones) composes in the guest while the host shows its plain layout, the badge names the guest's source, and the host gets its source back on resign, at the end, and after a crash at the next `paddock app list`.
- New: a lone press of the Globe key on a session window switches the guest's input source, not the host's; Reduce Motion and Increase Contrast of the host go to the guest.
- New: the guest display is the union of the host screens at the main scale (`PADDOCK_MACVM_DISPLAY` overrides it), the start lines name two scales, and a window in the gap between two screens goes onto the nearest screen.
- New: an HTML clipboard item without plain text gets the text of the HTML, a TIFF image without PNG gets a PNG, and an image over 16 MiB crosses as its PNG or not at all with the badge.
- `paddock app status --json` has `health.input_source`, the guest's input source. `packaging/macos/checks/macvm-input.sh` checks the layouts, Pinyin, the Globe key, the restore, two displays and Spaces on a Mac.
