- New: `paddock board` shows every project, ticket and agent run at a glance, the most urgent first, with the waiting approvals and the held compile slots at the top. `--json` prints the data for the Omarchy panel (version 1), and `--watch` draws it again on each change. `paddock help board-guide` explains the states.
- New: paddock records the prompt file of `paddock run --detach --prompt-file` and of `paddock-host spawn --prompt-file`, so the board maps each run to its ticket in `.paddock/tickets/`.
- Fixed: a ticket file name with control characters can no longer send escapes to the terminal through `paddock board`. The text view puts a run without a ticket among the tickets by its state, so the most urgent line comes first. A detached run that fails to start no longer leaves its prompt record.
- Fixed: bidi and zero-width characters in a ticket ID, title or `Status:` line, or in a run's text, harness, model or slot holder, can no longer reorder a line of `paddock board`. In `--json`, paddock writes U+0080 to U+009F (with the 8-bit CSI U+009B), DEL and the invisible characters as `\uXXXX` escapes. The `file` and `path` values stay exact, so the panel opens the same file.
