- New: `paddock run --profile default` works for Seatbelt runs on macOS. The sandbox home is a private copy of the harness's data roots, made with APFS clones (`clonefileat`) where the volume has them and with plain copies under `[storage] shadow_copy_limit_mib` where it does not. At the end paddock compares the copy with a record that it took after its own writes, prints what the run added, changed and deleted, and removes the run folder. Nothing goes back to the host, as on Linux. The VM backend refuses `--profile default`.
