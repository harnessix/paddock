- Changed: paddock keeps the windows of a macOS guest app apart inside the guest, so every session window shows its window live, also when the app opens its windows on top of each other. A window that opens, moves or grows onto another one goes to the nearest free place in the guest, and its session window stays where it is on the Mac.
- Changed: The guest display of a macOS guest session is twice as wide as the host screens, for the room that keeps the windows apart. `PADDOCK_MACVM_ROOM` sets the extra width (`0` for none). A suspended session from an earlier version starts cold once, because its display size changed. A full screen guest window is as wide as the guest display, so its right part does not show; `PADDOCK_MACVM_ROOM=0` avoids this.
