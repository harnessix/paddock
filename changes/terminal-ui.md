- New: `paddock tui` opens a terminal interface for runs, approvals, mail and the board. It works with the keyboard alone or with the mouse, in 80x24 and wider terminals, in light and dark themes. `--plain` draws no boxes and uses no mouse and no alternate screen, and `--readonly` hides every action. The interface is the separate package `@harnessix/paddock-tui` (`tui/` in the repository). paddock starts a `paddock-tui` binary next to it or on PATH. It never downloads the interface with npx, because npx would run code from npm and from the project folder outside the sandbox. Without the binary, it prints the install command.
- New: `paddock view ID --tail [LINES]` prints the end of the output of a run (at most 120 lines) without control characters and without the empty lines of the screen, and `--json` prints it as JSON (`paddock.view-tail/v1`). No window opens.
