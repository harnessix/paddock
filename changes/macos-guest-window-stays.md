- Changed: A host drag of a macOS guest session window moves only the window on the Mac. The guest window stays where it is, and the guest gets no `window.move`, also at the release. Each session window keeps its own offset, and its menus, popovers, sheets and input method candidates open at that offset.
- Changed: A live resize of a macOS guest session window follows faster. The agent's reply carries the new frame, the session handles agent events at once instead of after up to 50 ms, and the agent skips the position and the full window poll during a resize. Until the guest has drawn the new size, the host covers the rest with the window's edge colors, never the guest desktop.
- New: Each resize of a macOS guest session window writes its timings into the event log, as the line `the host resize ended`.
- New: Where another guest window lies on an unfocused session window, the host shows the window's last picture or its edge color. A click there waits until the guest raised the window.
