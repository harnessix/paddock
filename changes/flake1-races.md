- Security: on macOS, the guest agent refuses `clock.set`, `configure`, `data.prepare` and `shutdown` from the moment that it answers `app.launch`. Before, a request with the guest password that came right after the launch passed the guard until the next window poll. A second `app.launch` in that moment started a second app.
- Fixed: `paddock wait` sometimes gave exit code 2 and "ended without a final status" for a detached run that ended with a code. It read the end event of the mailbox before it read whether the run ended. A run that wrote its event and ended between the two reads looked like a run without an end event. `paddock wait` now reads in the other order, and it waits while the run holds its mailbox. The pane also writes the end event before it saves the end in its run record.
