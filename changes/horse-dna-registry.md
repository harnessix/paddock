- New: (experimental) the core of a DNA registry. A reference `registry://org/name@version` (or `@latest`, or `@sha256:HASH`) resolves through a list of index folders to a manifest and the canonical DNA text it names. A manifest is signed with an Ed25519 key, and a local trust policy lists which keys may sign for which org; an unsigned or untrusted artifact is refused by default. A published version cannot change. The hash of a published DNA is its hash in the horse store. There is no command for it yet.
