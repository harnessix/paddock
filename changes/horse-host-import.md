- New: (experimental) `paddock horse import HARNESS` reads chosen host sessions of Claude Code, Codex, Grok Build, agy or dsh into the horse store: by native id (the name of the session, never a folder above it), with `--path`, or with `--all`. `--list` shows the sessions that paddock can read. paddock reads a private copy of each file, so the host files do not change. A second import adds the new rows; the rows that the store has stay.
