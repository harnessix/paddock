- (experimental) New: an interactive Codex run in horse mode gets its queued entries between turns. paddock sets Codex's `notify` program in the sandbox copy of `config.toml` (a `notify` of the user still runs afterwards), and types each entry into the TUI through its pty relay when the turn is done and the screen shows the idle input row. The rollout file shows each landing, and `paddock horse append --interrupt` stops the running turn with Esc for an urgent entry. A Codex version without a `[horse.pty]` profile table, or a run with no terminal, keeps the entries queued and says so in one line.
- Changed: a swap of a Codex session that an interactive run holds is refused until the run ends, and the custody goes on.
- Fix: when two terminal relays run in one process, a size change of the caller's terminal reaches each of them.
