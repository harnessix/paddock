- New: paddock for Mac, a native launcher for app mode in `mac/launcher/`. It has a menu bar item and one window with a sidebar of apps, questions and the base image. It shows the onboarding checklist, the base image build, the live grants of each app, and the uninstall sheet. It talks to paddock only through the CLI with `--json` and `paddock events --follow --json`. The launcher is not in a release yet. It needs the new CLI commands to work.
