- (experimental) New: an interactive Claude Code run in horse mode on a version with no checked channel gets its queued entries between turns through paddock's pty relay. paddock adds the session id and the `Stop` and `UserPromptSubmit` hooks to the claude command, with no channel. It types an entry only when no hook and no transcript row says that a turn runs, the screen shows the empty input row with no busy row, and the screen did not change for 1.5 seconds. `paddock horse append --interrupt` stops the running turn with Esc. A Claude Code version without a `[horse.pty]` profile table, a command that picks its own session, or a run with no terminal keeps the entries queued and says so in one line.
- Changed: at a safe point, an urgent entry of `paddock horse append --interrupt` goes out before older entries that are not urgent.
- Fix: the idle test of the pty relay no longer reads a cursor that a TUI draws on the first letter of its placeholder as text of the user.
