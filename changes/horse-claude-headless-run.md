- (experimental) In horse mode, a Claude Code child of `paddock-host spawn` runs under live custody: paddock starts `claude -p` over stream-json with a session id that it binds before the sandbox starts, gives the task as the first user entry, delivers inbox entries only after a turn ended, reads the transcript after every turn, and ends the child when its inbox is empty. The `run.end` event says `custody: "live"` with the turn and delivery counts. An interactive Claude Code run in horse mode still reads its transcripts only at the end.
