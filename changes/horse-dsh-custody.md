- New: (experimental) horse mode for dsh runs. `paddock run dsh --horse`, or `[horse] enabled = true` in the user configuration, starts `dsh --profile sdk` and paddock holds its sessions: every event of the SDK stream goes into the horse store as it comes. `--horse-id ID` continues a horse and resumes its newest session. `paddock horse append` queues an entry that paddock delivers when the session is idle. A prefix guard warns before a fork, an append, or a model, tool or cwd change that loses the cached prompt prefix, with the size of the lost part. `paddock horse status` shows the live sessions, their inboxes and the last guard verdict. Runs without horse mode do not change.
