- Security: Each file of a release has a GitHub build provenance attestation. `gh attestation verify FILE --repo harnessix/paddock` shows that the release workflow of this repository built the file from the commit of the tag. README.md, Install, has the steps. The release workflow checks that the tag did not move before it makes the attestations, and it runs every action from outside this repository at a pinned commit.
- Changed: The release workflow runs the CI checks on the commit of the tag and publishes nothing when one fails. CI, the release and the VM guest files build with the one Rust version of `rust-toolchain.toml`.
- Changed: A release never replaces a file that it already has. A new upload of a file with the same name must have the same sha256, or the release workflow stops.
