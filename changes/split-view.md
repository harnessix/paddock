- New: `paddock split` shows several terminals in one window, on paddock's own tmux server and never on yours. A pane can be a new sandbox run, a view of a running sandbox, a host shell, the board or, on macOS, the macOS guest. The header of each pane says `sandbox` or `host` in words and in color, and a sandbox header shows a badge from the board state: running, waits for you or ended. A program in a pane cannot change its header. Ctrl-B d leaves the split and the sandboxes keep running. `paddock split add` adds a pane, `paddock split ls` lists them, and `paddock help split-guide` explains the split.
