- New: (experimental) The horse prefix guard reads the requests that Claude Code records in its transcript. For a Claude Code session, the guard takes the system prompt and tool shape and the time of the last request from these records. A shape change shows as a cache break from token 0, with its cost at the cache-write price. `paddock horse guard` prints the shape and the cache time: warm under 5 min, maybe warm under 1 h, and cold after.
