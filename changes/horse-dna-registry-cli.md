- New: (experimental) `paddock horse registry` manages published DNA on the host: `key new` and `key show` for the signing key, `trust add` and `trust list` for trusted keys, `index add`, `list`, `resolve` (manifest, trust verdict and hash, without an import), `publish` (signed with the key of the host, or `--unsigned`) and `sync` (`git pull --ff-only` for an index that is a git checkout). `paddock horse dna use HORSE REF` grafts published DNA into a horse.
- New: (experimental) in a horse-mode sandbox, `paddock-host horse registry fetch REF [--use]` and `paddock-host horse registry sync INDEX` go through the broker. The user approves each request, the host does the work, and the device ledger gets one line. A denied fetch writes nothing. The answer holds no path, key, index name or trust entry.
