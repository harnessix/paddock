- New: (experimental) the horse store reads Claude Code 2.1.317 transcripts row by row. It keeps the rows that Claude Code drops when it rewrites a large transcript. It writes a session or a fork back as a transcript in the shape of a native `/branch` fork. Other versions are refused. The hidden commands are `paddock horse ingest-claude` and `paddock horse project-claude`.
- New: (experimental) in horse mode, a Claude Code child of `paddock-host spawn` runs as `claude -p` over stream-json, with a session id that paddock picks.
- New: (experimental) an interactive Claude Code in horse mode gets queued entries through the pty relay. paddock adds the session id and the `Stop` and `UserPromptSubmit` hooks to the claude command. A command that sets `--resume`, `--continue` or `--session-id` keeps the entries queued.
- New: (experimental) `paddock-host channel` is an MCP channel server that pushes queued entries into an interactive Claude Code, and `paddock-host horse safe-point stop|prompt` lets its hooks report the safe points. paddock uses the channel only for Claude Code 2.1.318, so a horse run does not use it yet.
- New: (experimental) for a Claude Code session, the prefix guard reads the request shape that Claude Code records in its transcript. `paddock horse guard` shows the shape and the cache time: warm under 5 minutes, maybe warm under 1 hour, and cold after.
