- New: (experimental) a run with `--profile default --horse` that continues a host session records the host session in horse. The host session comes from the snapshot before the run, and the session of the run is a fork of it at the last row that both have. Its lineage starts with the lineage of the host session. When the host session came in with `paddock horse import` or `paddock horse adopt`, the session of the run joins that horse at the end of the run and keeps the run as its origin. The host session does not get the rows of the run, and the run prints one `horse:` line that says so. A failure of this lineage never stops the run.
